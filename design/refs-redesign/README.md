Что видно в рефах (наблюдения, не решения — визуальные решения за пользователем):
- почти чёрный графит, панели чуть светлее фона, скругления крупные, без рамок-обводок
- активный пункт сегмента и главная кнопка — светлые «пилюли» на тёмном
- плавающие панели и поповеры поверх рабочей области, модалки — поверх размытого фона
- монохром, цвет только точечно (аватары, переключатели, градиентный баннер)
- рабочая область (сцена) в центре — главный элемент экрана

Прямые параллели с программой: дерево сцены → список окон/элементов редактора;
инспектор → карточка элемента; Community → будущая библиотека пресетов; экспорт-поповер →
«Собрать и установить».
