### Форматы (основа)
- Ключ пака: `keyOffset = tableBase + (compressedSize mod 1024)`, `tableBase` 0x21CCD0 (AionEmpire) / 0x200430 (4Game) в `bin64/crysystem.dll`
- Бинарный XML: все 256 XML пересобираются байт в байт (`npm run selftest`). DDS: чтение A8R8G8B8/DXT1/3/5, запись A8R8G8B8
- Интерфейс клиент читает из `l10n/<язык>/data/data.pak` (`UI/…`), `data/ui/*.pak` — вторая копия; пишем в обе
- Свои картинки программы — `textures/ui/zz_builder.pak` (квадратная карта, разметка, `bld_el_*`, **`bld_grip`**); атласы Classic — `zz_classic_look.pak`
- Строки: `Strings/client_strings_*.xml` (UTF-16, `<name>STR_…</name><body>…</body>`). Названия зон — `STR_ZONE_NAME_<КОД>`
- Шрифты игры: `l10n/rus/data/data.pak` → `Fonts/fontshader.xml` (шейдер → гарнитура, `logical_size`, цвет; rus: Calibri / Myriad Pro 12 px) + `Fonts/CALIBRI.TTF`, `MYRIADPR.TTF`

### Окна HUD мышью в игре (03.10) — итоговые правила, всё проверено в игре
- **Что держит окно HUD:** привязка `h_pos_align`/`v_pos_align` + флаги `not_movable`/`not_active`/`transparent`/`not_focusable`. Снятие — `profile.hudFree` → `layout[id].free` → `hud.applyEdit({free})`, повтор в конце `buildDialog`
- **За что тащат:** окна с ячейками (бафы, ряды умений, боковая панель) — за ячейки и пустое место; окна без ячеек (карта) — только за тело окна (рамку-пресет). Тело без видимой подложки — **`bld_grip`**: `hud.gripLibrary()` (Skin + Preset `type=window` в `version4.xml`), `hud.gripAtlas()` (8×8, alpha 1/255, в zz_builder.pak); ставится окну без своего пресета. Плюс `hud.addGrip` — окно шире на 16 px справа, `title_frame` на всё окно
- **Таскаются:** бафы, дебафы, мини-карта, панель умений, боковая панель III, ряды Ctrl/Alt, кнопка меню (`hud.FREE_WINDOWS`, список в «Виде интерфейса» `LK_FREE`)
- **Не таскаются (держит код):** цель, бафы цели, портрет с HP/MP — убраны из списка, остаются родными
- **Место НЕ сохраняется:** игра не запоминает перетащенное (после перезахода окна на обычных местах), расстановки в файлах клиента нет (system.cfg — только графика). **Координаты из файла для бафов, карты, панели умений, HP/MP, меню, цели игра не берёт** (проверено: записанные карта x 1772, панель 729,917 — в игре всё на обычных местах)
- **Ряды Ctrl/Alt** без привязки встают по файлу → сборка ставит их стопкой над `ctn_shortcut` основной панели (Ctrl y 858, Alt 815, зазор 3; от места панели в файле, правки рамки панели не в счёт)
- В профиле пользователя остались `layout[…].frame` от отменённого режима «Двигать окна» (бафы, дебафы, карта, панель, HP/MP, цель, меню) — игра их не читает
- Постоянное место — только приёмами через размер окна: бафы «сдвинуть влево», карта «справа вверху» (`arrange.mapTopRight`)

### Скраббер — ползунки и поля цвета (15.10) — `ui/scrubber.js`, стили `.scrub` в `app.css`
- Дорожка 40, скругление `--radius-sm`: подпись слева и значение (`<b>`) справа внутри дорожки, засечки через 10 %, заливка до бегунка (`--p` из js), бегунок — черта 4×18 в невидимой ручке 16. Цвет — `.scrub--color`: подпись, образец 18 и поле hex 84 (ввод верного hex сразу шлёт `input`/`change` в цветовой input, неверный откатывается при уходе)
- Механика — родные `input range/color`, обработчики разделов не тронуты. `value` у каждого подключённого input перехвачен на экземпляре, чтобы заливка и hex успевали за `inp.value = …` из кода; дорисованные (бафы, карты, цвета цифр) подключает MutationObserver

- Проверено в браузере (`tools/serve.py`): 21 скраббер, заливка от значения и от `value =`, hex ↔ образец, обрезаний нет. **В Electron не проверено.** Карты на выдуманных данных не открылись — разметка та же

## Что НЕ сработало
Каждая строка стоила итерации, **не повторять**:
1. Правка только `data/ui/*.pak` — клиент читает `l10n/<язык>/data/data.pak`
2. Двигать окна HUD координатами x/y — игра не берёт их для бафов, карты, панели, HP/MP, меню, цели (03.10 проверено окончательно)
3. Снимать только `not_movable` — окно держит привязка `h/v_pos_align`; снимать всё (см. «Окна HUD мышью»)
4. «Место из программы» (режим «Двигать окна» + `not_movable`) — координаты игнорируются, окна ещё и перестали таскаться. Удалено
5. Надеяться, что игра запомнит перетащенное, — не запоминает, после перезахода окна на обычных местах
6. Видимая подложка `v4_tooltip` как режим расстановки и «подложка только при перетаскивании» — второе невозможно (пресет `type=window` — одно состояние `frame`; подложку отдельных панелей показывает код)
7. Освобождать ряды Ctrl/Alt без стопки — налезают на основной ряд
8. Таскать цель и HP/MP — не двигаются ни с телом, ни с подложкой
9. Цель в «Обычном стиле» — 10 итераций; в «Стиле Aion» стоит по центру сама
